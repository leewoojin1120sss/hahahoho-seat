BGM LIBRARY - V8

가장 쉬운 사용법
1. 이 폴더에 MP3 / M4A / AAC / WAV / OGG / FLAC 음악을 넣습니다.
2. 프로젝트 루트의 refresh_music_library.bat 를 더블클릭합니다.
3. index.html을 새로고침합니다.
4. BGM LIBRARY에서 AUTO PLAYLIST 또는 개별 곡을 선택합니다.

음악이 1곡 이상 등록되어 있으면 기본 Synth BGM보다 AUTO PLAYLIST가 우선 선택됩니다.
AUTO PLAYLIST는 한 곡이 끝나면 다음 곡으로 넘어가며 마지막 곡 뒤에는 첫 곡으로 돌아갑니다.
M4A는 브라우저가 해당 파일 내부 코덱(AAC 등)을 지원해야 재생됩니다.

GitHub Pages 등 온라인 배포에서는 music-library.js에 HTTPS 음원 URL을 직접 적어도 됩니다.
